Educational hacking simulator

TerminalHacker

Train in a simulated Linux desktop: scan networks, crack SSH, wipe logs, upgrade firewalls, and graduate into career contracts — without touching real systems.

View on GitHub How to run

13-lesson tutorial

Protected $500 training budget while you learn ifconfig, routing, VPN, privesc, and blue-team defense.

Desktop GUI

Terminal, Mail, Files, Shop, Job Board, and Training apps — or play pure CLI with --cli.

Career mode

Missions, rivals, seasons, operations, achievements, and autosave to ~/.terminalhacker/save.json.

Run locally

git clone https://github.com/TroublingRock/TerminalHacker.git
cd TerminalHacker
python3 main.py          # GUI (needs python3-tk on Linux)
python3 main.py --cli    # terminal-only fallback

Requires Python 3.10+. Debian/Ubuntu: sudo apt install python3-tk
